# 泵站值守台账

替代纸质台账的网页工具，纯前端实现，双击 `index.html` 即可使用，数据自动保存在浏览器本地。

## 功能

- 预置四台泵组，登记水位、启停，自动累计运行分钟
- 同一台泵连续运行满 45 分钟提示换泵；切换先起备用泵、再停旧泵，空档超过 2 分钟自动记违规
- 交接班时如有泵在运，须填交接人并登记剩余分钟，下一班接着计时（运行计时不清零）
- 水位回到安全线下才能停泵（换泵重叠期间除外）
- 四台泵都在运行或检修时，满 45 分钟的泵标为超时，不停机并提示缺备用泵
- 台账可导出 CSV（Excel 可直接打开打印）和 JSON 备份

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `js/pumpArchive.js` | 业务文件一：档案——四台泵组档案与台账登记 |
| `js/rotationRules.js` | 业务文件二：轮换规则——45 分钟换泵、2 分钟空档、水位停泵、超时判定、交接计算 |
| `js/localStore.js` | 业务文件三：本地存档——localStorage 持久化与 CSV/JSON 导出 |
| `js/app.js` | 页面交互层，把三个业务模块接到界面 |

## 使用

直接双击 `index.html` 打开；或在本目录起个静态服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```
