# 泵站值守台账（网页工具）

替代纸质台账的纯静态网页工具，无需安装、无需联网，数据仅保存在本机浏览器。

## 使用方法

任选其一：

- 直接双击打开 `index.html`（推荐 Chrome / Edge / Firefox）；
- 或在本目录启动静态服务后访问，例如 `npx serve .`。

> 直接用 `file://` 打开即可正常使用（ES 模块在现代浏览器本地文件下可运行）。

## 功能与规则

- 预置 **四台泵组**（1#～4#泵组），记录运行/备用/检修状态与**累计运行分钟**。
- **水位登记**：可调整安全线（默认 5.00 米）；水位在安全线以上时，最后一台运行泵禁止停止。
- **45 分钟换泵**：同一台泵连续运行满 45 分钟，换泵按钮才可用；换泵自动执行「先起备用泵，再停旧泵」，备用泵按累计运行分钟最少者选取。
- **空档违规**：水位高于安全线时全部停泵，空档超过 **2 分钟**自动记一条违规（界面同步倒计时告警）；换泵流程无空档。
- **缺备用泵超时**：四台泵都在运行或检修时，在运泵标记「超时·缺备用泵」，**不停机**，恢复备用后自动解除。
- **交接班**：交班人、接班人必填；交接时仍在运行的泵逐台填本轮剩余分钟，下一班按剩余分钟折算后**继续计时**。
- 台账按类型筛选（违规/超时、启停换泵、水位、交接、检修），并支持 JSON **导出/导入/清空**存档。

## 文件结构（三个业务文件分离）

| 文件 | 职责 |
| --- | --- |
| `js/rotation.js` | **轮换规则**：45 分钟周期、2 分钟空档、备用泵选择、超时与停泵判定（纯函数） |
| `js/archive.js` | **泵组档案**：四台泵状态、水位/启停/换泵/检修/交接/违规事件登记与校验 |
| `js/store.js` | **本地存档**：localStorage 读写、JSON 导入导出、清空 |
| `js/app.js` | 页面渲染与交互（每秒巡检） |
| `index.html` / `styles.css` | 页面结构与样式 |
| `js/test-rules.mjs` | 规则冒烟测试：`node js/test-rules.mjs` |
